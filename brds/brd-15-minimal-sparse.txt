left blank or marked [BLANK]. Use this BRD to verify:

(a) The BRD upload endpoint returns a successful 200 with character
    count of 0 instead of crashing.

(b) The BRD extraction endpoint returns a graceful error (HTTP 400 or
    502) explaining that no fields could be extracted, rather than a
    500 server error.

(c) The intake-completeness endpoint returns missing_fields covering
    every field, with completeness_percent = 0, and
    ready_for_risk_calculation = false.

(d) The risk-factor generation endpoint either refuses to run with an
    error message, or runs and produces a RiskAssessment with all
    seven category scores = 0, inherent_score = 0, inherent_rating =
    LOW, residual_score = 5 (base floor), residual_rating = LOW.

(e) The system does NOT crash, does NOT leak stack traces, and does
    NOT silently default missing booleans to True (which would falsely
    trigger risk-floor rules).

This is the most important negative test for robustness - it validates
the empty-input boundary of every endpoint in the workflow.
